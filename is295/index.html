Information Systems Capstone / Special Project

IS 295 Resource Hub

Writing guidelines and templates for the IS 295 manuscript and the Software Requirements Specification (SRS). Read the guidelines first, then copy the matching LaTeX template on Overleaf to start writing.

Use of LaTeX is highly preferred. It preserves the required formatting (headings, numbering, table of contents, and citations) no matter how often the document is edited, unlike Word files, which tend to break as content changes.
